# Database Migration Files

This directory contains database migration files generated by Alembic.

## Naming Convention

Migration files follow this format:
```
YYYYMMDD_HHMMSS_<type>_<description>.py
```

### Types:
- `create`: New table creation
- `alter`: Table modification
- `drop`: Table/column removal
- `seed`: Data seeding
- `func`: Function/procedure changes
- `idx`: Index operations
- `constraint`: Constraint changes

### Examples:
```
20251101_143000_create_job_table.py
20251101_143500_alter_job_add_status.py
20251101_144000_idx_job_status.py
20251102_090000_seed_initial_jobs.py
```

## Best Practices:

1. One conceptual change per migration
2. Always include both upgrade() and downgrade()
3. Test migrations both ways before committing
4. Include helpful docstrings describing the changes
5. Keep data migrations separate from schema changes
6. Use explicit name lengths in varchar fields
7. Add appropriate indexes with table creation
