04. 그래프 확장기능﻿

하나의 작업, 테이블에 대해서 조회된 그래프에서 마우스로 노드를 하나 선택한다.

노드가 그래프에서 더이상 연장될 부분이 있다면 마우스 우측으로 메뉴를 보일 수 있다.

그래프 확장﻿이라는 버튼을 누르면 그 그래프에서 neighbor 그래프를 한번더 얻어서 지금 보이는 그래프와 합쳐 진다.

neo4j 에서 노드 기준으로 연결된엣지 노드를 조회 확대하는 과정과 같다.

시각적인 이펙트는 가능하면 neo4j 와 비슷하게 해주면 좋다.

상세 기능 요구사항 (Function Requirements)
노드 선택

그래프 내에서 사용자는 마우스로 특정 노드를 클릭하여 선택할 수 있어야 한다.

이 때 선택된 노드는 하이라이트 등의 시각적 표시로 명확히 구분되어야 한다.

우클릭 메뉴 표시

선택된 노드가 추가로 확장 가능한 연결(이웃 노드)을 가지고 있으면, 마우스 우측 클릭 시 확장 메뉴가 나타나야 한다.

이 메뉴에는 최소한 "그래프 확장" 버튼이 포함되어야 한다.

그래프 확장 동작

"그래프 확장" 버튼 클릭 시, 선택한 노드의 연결된 이웃 노드와 엣지를 추가로 조회한다.

조회된 neighbor 그래프 데이터를 기존 그래프에 병합하여 화면에 다시 표시한다.

데이터 조회는 Neo4j의 Cypher 쿼리에서 MATCH (n)-[r]-(m)처럼 노드 기준으로 연결된 엣지와 노드를 가져오는 것과 같다.

시각 효과

그래프 확장 시 부드러운 애니메이션을 제공하여 추가된 노드와 엣지가 자연스럽게 등장하도록 한다.

Neo4j Browser에서 제공하는 노드와 엣지 확장 시 나타나는 이펙트를 참고해 구현한다.

레이아웃 변화, 노드 간 거리 자동 조절 등 사용자 경험 향상을 위한 시각적 연출을 포함한다.

성능 및 사용자 경험

확장 요청마다 과도한 데이터 로드를 막기 위해 확장 범위나 최대 노드 수를 제한할 수 있어야 한다.

확장된 그래프는 기존 그래프와 자연스럽게 통합되며, 중복 노드/엣지는 자동으로 처리한다.

이 기능 요구사항은 대화형 그래프 탐색 UX를 제공하여, 사용자가 그래프 데이터 내 연관 관계를 직관적으로 더 깊게 탐색할 수 있도록 돕는 것을 목표로 한다. neo4j﻿의 시민 수준 기능과 비슷한 수준의 직관적 확장 경험 제공을 권장한다.
