15. UI Design Renewal
Overview

The Lineage Explorer UI will be reorganized and redesigned based on observed usage patterns and improved usability goals. This renewal introduces structural adjustments, additional information panels, and graphical behavior updates.

Key Changes
1. Layout and Component Reorganization

The UI layout will be restructured following the current Lineage Explorer pattern.

Several existing menu sections will be removed or relocated for clarity and usability.

Graph control elements will be grouped more intuitively under newly defined sections.

2. Node-Type–Specific Enhancements
Table Node

Add a “Data Loaded Time” field to display the latest ingestion timestamp.

Introduce a new Metadata accordion section with expandable details.

Job Node

Add a new “Job Run History” tab allowing users to fetch execution logs via API.

The tab will appear in the Detail Panel under a new section named Runs.

3. Graph Behavior Changes

Convert the lineage graph from a dynamic graph to a static graph model.

Reduces irregular layout shifts.

Increases predictability of node positions.

Allows controlled expansion behavior.
