# 15. UI Design Renewal – Work Summary

## Status
✅ Layout, detail panels, and graph behavior have been redesigned and implemented in the latest UI build (Nov 19, 2024).

## What Was Delivered

### 1. Layout & Controls
- Replaced the top navigation tabs with a streamlined toolbar.  
- Added a left-side control drawer (Explorer Controls) and a right-side detail drawer that can be toggled and resized (20–50% of viewport width).  
- Added Graph/List view toggles: the List view shows the current nodes in a table with CSV download support.
- Consolidated zoom controls and reset actions into the toolbar with new icons.

### 2. Table Node Experience
- Detail panel now has:
  - “Fully qualified name” header section.
  - Tabs (`Schema`, `Load timeline`) in their own block.  
  - Load timeline fetches `/api/v1/tables/{table}/load-history` asynchronously with spinner placeholders and interval columns (start/end/human summary).  
  - Trigger Jobs block remains at the bottom with ON/OFF controls.

### 3. Job Node Experience
- Job detail panel includes a dedicated “Run history” tab.  
- Selecting the tab calls `/api/v1/jobs/{job_id}/run-history` (dummy data, >=1s response) and renders status/start/end/duration/trigger info with loading placeholders.

### 4. Graph Behavior & Interactions
- Graph is treated as static after initial render: reset now replays the last search result (clear expansions, center at 100% zoom).  
- List view, minimap placement, and toolbar visibility stay in sync with graph state.  
- Double-clicking a node toggles the detail panel open/closed.  
- Table-specific taps re-open the detail panel automatically even if previously collapsed.

## Next Steps
- Replace dummy load/run history APIs with real implementation.  
- Apply the same resizable/toggle treatment to the left control drawer if desired.  
- Continue polishing styling per remaining design tasks in `15.UI_design_renewal.txt`.
