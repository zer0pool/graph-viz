## Rollback Plan

### If Issues Arise

**Option 1: Gradual Rollback**
1. Revert API endpoint changes
2. Restore old GraphService temporarily
3. Keep new containers but use deprecated providers
4. Fix issues incrementally

**Option 2: Full Rollback**
1. Restore `src/lineage_manager/core/container.py` from backup
2. Restore `src/lineage_manager/services/graph_service.py` from backup
3. Restore `src/lineage_manager/core/database.py` from backup
4. Remove new container files
5. Revert API endpoint changes

**Backup Strategy**
```bash
# Before starting, create backup branch
git checkout -b backup/before-refactoring
git commit -am "Backup before refactoring"
git checkout main

# If rollback needed
git checkout backup/before-refactoring
git checkout -b rollback/refactoring
# Cherry-pick any needed changes
```
