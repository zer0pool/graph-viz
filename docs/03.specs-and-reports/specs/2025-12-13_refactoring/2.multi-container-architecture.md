## Overview

### Goal

Separate the monolithic `GraphContainer` into **5 domain-specific containers** for better separation of concerns, independent testing, and microservice readiness.

### Before: Single Container

```
┌──────────────────────────────────────────────────────────┐
│              GraphContainer (God Container)              │
│                                                           │
│  ┌─────────────┐  ┌──────────────┐  ┌─────────────┐    │
│  │  Database   │  │ Job Manager  │  │    OIDC     │    │
│  │   Config    │  │   Adapter    │  │  Provider   │    │
│  └─────────────┘  └──────────────┘  └─────────────┘    │
│                                                           │
│  ┌─────────────┐  ┌──────────────┐  ┌─────────────┐    │
│  │   Graph     │  │     Job      │  │    User     │    │
│  │  Service    │  │   Service    │  │  Service    │    │
│  └─────────────┘  └──────────────┘  └─────────────┘    │
│                                                           │
│  ┌─────────────┐  ┌──────────────┐                      │
│  │  BigQuery   │  │ Initializer  │                      │
│  │  Service    │  │   Service    │                      │
│  └─────────────┘  └──────────────┘                      │
│                                                           │
│  ❌ Everything in one container                          │
│  ❌ Unclear domain boundaries                            │
│  ❌ Tests load all dependencies                          │
└──────────────────────────────────────────────────────────┘
```

### After: Multi-Container

```
┌─────────────────────────────────────────────────────────────────┐
│            ApplicationContainer (Root Orchestrator)             │
└────────┬────────────┬────────────┬────────────┬─────────────────┘
         │            │            │            │
         ↓            ↓            ↓            ↓
┌────────────┐ ┌─────────────┐ ┌──────────┐ ┌──────────────┐
│   Core     │ │    Graph    │ │   Job    │ │     User     │
│ Container  │ │  Container  │ │Container │ │  Container   │
│            │ │             │ │          │ │              │
│ - Database │ │ - Query     │ │ - Adapter│ │ - Service    │
│ - Config   │ │ - Command   │ │ - Service│ │ - Repos      │
│ - Auth     │ │ - Sync      │ └──────────┘ └──────────────┘
└────────────┘ │ - Init      │
               │ - Helper    │      ┌──────────────┐
               └─────────────┘      │  BigQuery    │
                                     │  Container   │
                                     │              │
                                     │ - Service    │
                                     └──────────────┘

✅ Clear domain separation
✅ Independent testing
✅ Easy to extend
```

## Container Design

### 1. CoreContainer (Infrastructure Layer)

**Responsibility**: Database, configuration, and authentication infrastructure

```python
# src/lineage_manager/core/containers/core_container.py

from dependency_injector import containers, providers
from lineage_manager.core.database import Database, db
from lineage_manager.core.auth import OIDCProviderClient


class CoreContainer(containers.DeclarativeContainer):
    """Core infrastructure container for database, config, and auth."""
    
    # Configuration
    config = providers.Configuration()
    
    # Database
    database = providers.Singleton(Database)
    
    # Write Sessions (for mutations)
    write_session_factory = providers.Singleton(lambda: db.write_session_factory)
    write_session = providers.Factory(write_session_factory)
    
    # Read Sessions (for queries)
    read_session_factory = providers.Singleton(lambda: db.read_session_factory)
    read_session = providers.Factory(read_session_factory)
    
    # Authentication
    oidc_provider = providers.Singleton(
        OIDCProviderClient,
        issuer=config.oidc_issuer_url,
        client_id=config.oidc_client_id,
        client_secret=config.oidc_client_secret,
        redirect_uri=config.oidc_redirect_uri,
        audience=config.oidc_audience,
        scopes=config.oidc_scopes,
        cache_seconds=config.oidc_jwks_cache_seconds,
    )
```

**Provides**:
- Database connections (read/write)
- Session factories
- OIDC authentication
- Configuration management

**Dependencies**: None (base layer)

### 2. JobContainer (Job Manager Domain)

**Responsibility**: External Job Manager integration

```python
# src/lineage_manager/core/containers/job_container.py

from dependency_injector import containers, providers
from lineage_manager.adapters.job_manager_adapter import JobManagerAdapter
from lineage_manager.services.job_service import JobService


class JobContainer(containers.DeclarativeContainer):
    """Job Manager domain container."""
    
    # Dependencies from other containers
    core = providers.DependenciesContainer()
    
    # Adapter (External Integration)
    job_manager_adapter = providers.Singleton(
        JobManagerAdapter,
        base_url=core.config.job_manager_url,
    )
    
    # Service (no DB access - external API only)
    job_service = providers.Factory(
        JobService,
        job_manager=job_manager_adapter,
    )
```

**Provides**:
- JobManagerAdapter (external API communication)
- JobService (run history, etc.)

**Dependencies**: CoreContainer (config)

**Note**: No database access - only external API calls

### 3. UserContainer (User Management Domain)

**Responsibility**: User profile and authentication management

```python
# src/lineage_manager/core/containers/user_container.py

from dependency_injector import containers, providers
from lineage_manager.repositories.user_repository import UserRepository
from lineage_manager.repositories.job_repository import JobRepository
from lineage_manager.services.user_service import UserService


class UserContainer(containers.DeclarativeContainer):
    """User management domain container."""
    
    # Dependencies from other containers
    core = providers.DependenciesContainer()
    
    # Repositories (direct injection - simpler than UoW for single domain)
    user_repository = providers.Factory(
        UserRepository,
        db=core.write_session,  # User updates need write access
    )
    
    job_repository = providers.Factory(
        JobRepository,
        db=core.read_session,  # Read-only for listing user's jobs
    )
    
    # Service with direct repository injection
    user_service = providers.Factory(
        UserService,
        user_repository=user_repository,
        job_repository=job_repository,
        session=core.write_session,
    )
```

**Provides**:
- UserService (login, profile)

**Dependencies**: CoreContainer (database)

**Pattern**: Direct repository injection (not UoW) since it only needs 2 repositories

### 5. GraphContainer (Graph Domain)

**Responsibility**: Graph lineage data management

```python
# src/lineage_manager/core/containers/graph_container.py

from dependency_injector import containers, providers
from lineage_manager.core.uow import GraphUnitOfWork, GraphReadOnlyUnitOfWork
from lineage_manager.services.graph_query_service import GraphQueryService
from lineage_manager.services.graph_command_service import GraphCommandService
from lineage_manager.services.graph_sync_service import GraphSyncService
from lineage_manager.services.graph_initializer import GraphInitializerService
from lineage_manager.services.helpers.graph_traversal_helper import GraphTraversalHelper


class GraphContainer(containers.DeclarativeContainer):
    """Graph domain container for lineage graph management."""
    
    # Dependencies from other containers
    core = providers.DependenciesContainer()
    job = providers.DependenciesContainer()
    
    # Write UoW (for mutations)
    write_uow = providers.Factory(
        GraphUnitOfWork,
        db=core.write_session_factory,
    )
    
    # Read UoW (for queries)
    read_uow = providers.Factory(
        GraphReadOnlyUnitOfWork,
        db=core.read_session_factory,
    )
    
    # Helpers
    traversal_helper = providers.Factory(
        GraphTraversalHelper,
        uow=read_uow,  # Read-only for traversal
    )
    
    # Services
    query_service = providers.Factory(
        GraphQueryService,
        uow=read_uow,  # Use read session
        traversal_helper=traversal_helper,
    )
    
    command_service = providers.Factory(
        GraphCommandService,
        uow=write_uow,  # Use write session
    )
    
    sync_service = providers.Factory(
        GraphSyncService,
        uow=write_uow,  # Use write session
        job_manager=job.job_manager_adapter,
        command_service=command_service,
    )
    
    initializer_service = providers.Factory(
        GraphInitializerService,
        job_manager=job.job_manager_adapter,
        graph_service=command_service,
    )
```

**Provides**:
- GraphQueryService (read operations)
- GraphCommandService (write operations)
- GraphSyncService (sync operations)
- GraphInitializerService (initialization)
- GraphTraversalHelper (shared BFS algorithms)

**Dependencies**: CoreContainer (database), JobContainer (adapter)

### 6. ApplicationContainer (Root Container)

**Responsibility**: Orchestrate all domain containers

```python
# src/lineage_manager/core/container.py

from dependency_injector import containers, providers
from lineage_manager.core.containers.core_container import CoreContainer
from lineage_manager.core.containers.graph_container import GraphContainer
from lineage_manager.core.containers.job_container import JobContainer
from lineage_manager.core.containers.user_container import UserContainer
from lineage_manager.core.containers.bigquery_container import BigQueryContainer


class ApplicationContainer(containers.DeclarativeContainer):
    """Root application container that wires all domain containers."""
    
    wiring_config = containers.WiringConfiguration(
        packages=["lineage_manager.api.v1.endpoints"]
    )
    
    # Core infrastructure
    core = providers.Container(CoreContainer)
    
    # Domain containers
    job = providers.Container(
        JobContainer,
        core=core,
    )
    
    user = providers.Container(
        UserContainer,
        core=core,
    )
    
    bigquery = providers.Container(
        BigQueryContainer,
        core=core,
    )
    
    graph = providers.Container(
        GraphContainer,
        core=core,
        job=job,
    )
```

## Domain-Specific UoW Patterns

### Pattern 1: GraphUnitOfWork (Multi-Repository Domain)

Use when service needs **multiple repositories** and **complex transactions**.

```python
# src/lineage_manager/core/uow.py

class GraphUnitOfWork(BaseUnitOfWork):
    """Unit of Work for Graph domain (5 repositories)."""
    
    def __init__(self, db: Session):
        super().__init__(db)
        self.jobs = JobRepository(db)
        self.tables = TableRepository(db)
        self.job_table_links = JobTableLinkRepository(db)
        self.edges = GraphEdgeRepository(db)
        self.closures = ClosureRepository(db)
```

**Used by**: GraphCommandService, GraphSyncService

---

### Pattern 2: GraphReadOnlyUnitOfWork (Read-Only Domain)

Use when service only needs **read access** with **autocommit**.

```python
class GraphReadOnlyUnitOfWork(ReadOnlyUnitOfWork):
    """Read-only Unit of Work for Graph domain queries."""
    
    def __init__(self, db: Session):
        super().__init__(db)
        self.jobs = JobRepository(db)
        self.tables = TableRepository(db)
        self.job_table_links = JobTableLinkRepository(db)
        self.edges = GraphEdgeRepository(db)
        self.closures = ClosureRepository(db)
```

**Used by**: GraphQueryService, GraphTraversalHelper

---

### Pattern 3: Direct Repository Injection (Simple Domain)

Use when service needs **1-2 repositories** and **simple operations**.

```python
class UserService:
    def __init__(
        self,
        user_repository: UserRepository,
        job_repository: JobRepository,
        session: Session,
    ):
        self.users = user_repository
        self.jobs = job_repository
        self.session = session
```

**Used by**: UserService

**Benefits**:
- ✅ Lighter weight (only needed repositories)
- ✅ Easier testing (mock only what's needed)
- ✅ Clear dependencies

## Container Dependencies

### Dependency Graph

```
┌──────────────┐
│     Core     │ ← Base Layer (No dependencies)
└──────┬───────┘
       │
       ├─────────────────────────────────────┐
       │                                     │
       ↓                                     ↓
┌──────────────┐                      ┌──────────────┐
│     Job      │                      │     User     │
└──────┬───────┘                      └──────────────┘
       │                                     
       │                              ┌──────────────┐
       │                              │  BigQuery    │
       │                              └──────────────┘
       ↓
┌──────────────┐
│    Graph     │ ← Depends on Core + Job
└──────────────┘
```

**Rules**:
- ✅ Unidirectional dependencies (Acyclic)
- ✅ Core has no dependencies
- ✅ Graph depends on Job (for JobManagerAdapter)
- ❌ No circular dependencies

## API Endpoint Injection

### Graph Domain Endpoints

```python
# api/v1/endpoints/graph.py

from dependency_injector.wiring import inject, Provide
from lineage_manager.core.container import ApplicationContainer

# Query Endpoints → GraphQueryService
@router.get("/jobs/{job_id}")
@inject
async def get_job(
    job_id: str,
    service: GraphQueryService = Depends(
        Provide[ApplicationContainer.graph.query_service]
    ),
):
    return service.get_job(job_id)

# Command Endpoints → GraphCommandService
@router.post("/jobs")
@inject
async def register_job(
    job_data: JobRegister,
    service: GraphCommandService = Depends(
        Provide[ApplicationContainer.graph.command_service]
    ),
):
    return service.register_job(job_data)

# Sync Endpoints → GraphSyncService
@router.post("/sync/jobs")
@inject
async def sync_job(
    lineage: SchedulingLineage,
    service: GraphSyncService = Depends(
        Provide[ApplicationContainer.graph.sync_service]
    ),
):
    return service.sync_from_lineage(lineage)
```

### Job Domain Endpoints

```python
# api/v1/endpoints/jobs.py

@router.get("/jobs/{job_id}/run-history")
@inject
async def get_run_history(
    job_id: str,
    service: JobService = Depends(
        Provide[ApplicationContainer.job.job_service]
    ),
):
    return await service.get_run_history(job_id)
```

### User Domain Endpoints

```python
# api/v1/endpoints/users.py

@router.get("/users/profile")
@inject
async def get_profile(
    current_user: dict = Depends(get_current_user),
    service: UserService = Depends(
        Provide[ApplicationContainer.user.user_service]
    ),
):
    return service.get_profile(current_user["sub"])
```

### BigQuery Domain Endpoints

```python

@router.get("/tables/{table_name}/schema")
```

## Testing Patterns

### Pattern 1: Single Container Test

```python
# tests/containers/test_job_container.py

import pytest
from lineage_manager.core.containers.core_container import CoreContainer
from lineage_manager.core.containers.job_container import JobContainer


def test_job_service():
    # Setup
    core = CoreContainer()
    core.config.from_dict({"job_manager_url": "http://test"})
    
    job = JobContainer(core=core)
    
    # Test
    service = job.job_service()
    assert service is not None
    assert service.job_manager is not None
```

### Pattern 2: Container Integration Test

```python
# tests/containers/test_graph_container.py

def test_graph_sync_service():
    # Setup
    core = CoreContainer()
    core.config.from_dict({
        "job_manager_url": "http://test",
        "database_url": "sqlite:///:memory:",
    })
    
    job = JobContainer(core=core)
    graph = GraphContainer(core=core, job=job)
    
    # Test
    sync_service = graph.sync_service()
    assert sync_service is not None
    assert sync_service.job_manager is not None  # From JobContainer
    assert sync_service.command_service is not None  # From GraphContainer
```

### Pattern 3: Mock Container Test

```python
# tests/api/test_graph_endpoints.py

@pytest.fixture
def app_with_mock_graph():
    container = ApplicationContainer()
    
    # Mock GraphQueryService
    mock_query_service = Mock()
    mock_query_service.get_job.return_value = {"job_id": "test"}
    
    container.graph.query_service.override(mock_query_service)
    
    app = FastAPI()
    app.container = container
    return app


def test_get_job_endpoint(app_with_mock_graph):
    client = TestClient(app_with_mock_graph)
    response = client.get("/api/v1/graph/jobs/test")
    assert response.status_code == 200
```

## Benefits Summary

| Benefit | Description |
|---------|-------------|
| **Clear Separation** | Each container manages one domain |
| **Independent Testing** | Test only the containers you need |
| **Easy Extension** | Add new containers without modifying existing ones |
| **Microservice Ready** | Each container can become a separate service |
| **Explicit Dependencies** | Container dependencies are clearly defined |
